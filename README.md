# ⏱️ Chronometer - Stoppuhr-Anwendung

Eine einfache, funktionale Stoppuhr entwickelt mit JavaScript, HTML und CSS.

## ✨ Features

- Start/Stop Funktion
- Reset Funktion
- Zeitmessung in Millisekunden
- Responsive Design

## 🛠️ Technologien

- HTML5
- CSS3
- JavaScript (Vanilla)

## 💻 Installation & Verwendung

1. Repository klonen:
```bash
git clone https://github.com/NIC2EMZ/Chronometer-.git
```

2. Öffne die `index.html` Datei in deinem Browser
